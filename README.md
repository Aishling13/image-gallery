# Image gallery

A responsive and interactive image gallery built with **React** and **Vite**, using the **Unsplash API** to fetch photos of cats.

This gallery emphasises **mobile-first design**, looking great on mobile, tablet, desktop, and larger monitors. Each image has a hover effect to give visual feedback, and a heart icon in the top-left corner that changes to red with a smooth animation when clicked, mimicking “favouriting” an image. Currently, the gallery displays the first 10 images returned by the Unsplash API.

This project helped me strengthen my skills in **responsive design, React component architecture, API integration, and UI/UX interactions**.

**Tech Stack:** React, Vite, CSS, Unsplash API

**Live Demo:** [View Image Gallery on Vercel](https://image-gallery-eta-azure.vercel.app/)
